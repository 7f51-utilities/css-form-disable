🎯 Framework-Agnostic CSS Form Disable

Pure CSS Solution: This form uses only CSS to automatically disable the submit button when the form contains invalid fields. No JavaScript required!

Try the Form

The submit button will be automatically disabled until all fields are valid:

🚀 Works with Any Framework

Vanilla HTML/JS

<link rel="stylesheet" href="@7f51-utilities/css-form-disable/css"> <form> <input type="email" required> <button type="submit">Submit</button> <!-- Auto-disabled --> </form>

React

import '@7f51-utilities/css-form-disable/css' function MyForm() { return ( <form> <input type="email" required /> <button type="submit">Submit</button> </form> ) }

Vue

import VueFormDisable from '@7f51-utilities/css-form-disable' app.use(VueFormDisable, { customSelectors: ['.btn-primary'], theme: 'minimal' })

Laravel Blade

@vite(['resources/css/app.css']) {{-- Include: @import '@7f51-utilities/css-form-disable/css'; --}} <form> <input type="email" required> <button type="submit" class="btn-primary">Submit</button> </form>
